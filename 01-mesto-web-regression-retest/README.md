# 🧪 Регрессионное тестирование и верификация дефектов веб-приложения Mesto

Проект демонстрирует навыки проведения цикла регрессионного тестирования веб-интерфейса, локализации дефектов, работы с их жизненным циклом (Retest/Reopen) и оформления отчетности.

---

### 🛠 Стек и инструменты: Google Таблицы

---

### 📝 Описание проекта
**Mesto** — интерактивная социальная сеть для обмена фотографиями, включающая функционал добавления/удаления контента и систему лайков.

**Цель работы:** Проведение полного цикла регрессионного тестирования веб-версии приложения перед релизом и проверка качества исправления ранее обнаруженных дефектов.

---

### 🚀 Выполненные задачи и результаты

#### 🔹 Часть 1: Регрессионное тестирование
* **Прогон тест-кейсов:** Провела регрессионное тестирование на тестовом стенде по готовому набору из **17 тест-кейсов**.
* **Локализация дефектов:** Локализовала и задокументировала **7 новых дефектов**.
* **Приоритезация (Severity/Priority):**
  * 🔴 `1 Critical`
  * 🟡 `4 High`
  * 🟢 `2 Low`
* **Документирование:** Оформила баг-репорты с прикреплением артефактов (скриншоты, скринкасты, шаги воспроизведения, ОР и ФР).

📊 **Итоги первого прогона:**

| Статус | Количество |
| :--- | :---: |
| ✅ Passed (Пройдено) | 7 |
| ❌ Failed (Провалено) | 5 |
| 🚫 Blocked (Заблокировано) | 5 |

---

#### 🔹 Часть 2: Ретест и работа с жизненным циклом багов
* **Повторное тестирование:** Провела **Retest** для **15 баг-репортов**, переданных от команды разработки после исправления.
* **Верификация фиксов:** Проверила стабильность исправлений на тестовом стенде и валидировала статусы дефектов:
  * **Закрыто (Closed):** **10 баг-репортов** (дефекты успешно исправлены).
  * **Переоткрыто (Reopened):** **5 баг-репортов** из них `2 Blocker` и `3 Critical`.
