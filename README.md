# Портфолио проектов по ручному тестированию (Manual QA)

Добро пожаловать в репозиторий с примерами моей тестовой документации и артефактами тестирования, разработанными в ходе обучения в Яндекс Практикуме. 

Все проекты выполнены на основе реальных технических требований (ТЗ) и дизайн-макетов в Figma, прошли код-ревью и соответствуют индустриальным стандартам оформления документации.

---

## 🚀 Навигация по проектам

### 🛠 1. Дипломный проект: Комплексное тестирование Web + Mobile «Яндекс Самокат»
*   **Описание:** Сквозное End-to-End тестирование экосистемы сервиса аренды самокатов на двух платформах (Web и Mobile).
*   **Что сделано:** Спроектированы чек-листы для веб-экрана «Статус заказа», созданы матрицы валидации полей формы «Сделать заказ» (КЭ, ГЗ), написаны подробные тест-кейсы на логику и вёрстку мобильного приложения по макетам Figma. Проведено исследовательское тестирование.
*   **Папка проекта:** [Перейти к файлам](./06-diploma-samokat-e2e-testing/)

### 🌐 2. Тестирование REST/XML API бэкенда «Яндекс.Прилавок»
*   **Описание:** Изолированное тестирование новой функциональности бэкенда (модули корзины, наборов продуктов и интеграции с доставкой).
*   **Что сделано:** Проанализирована документация в Apidoc. В **Postman** протестированы REST-ручки (GET, POST, PUT, DELETE) с JSON-телами, а также XML-сервис расчета доставки. Проведена валидация HTTP-статус кодов и структуры ответов. Составлен Test Report.
*   **Папка проекта:** [Перейти к файлам](./05-grocery-rest-xml-api-postman/)

### 📱 3. Мобильное тестирование приложения «Яндекс Метро» (Android)
*   **Описание:** Функциональное и регрессионное тестирование сборки приложения после масштабного рефакторинга кода.
*   **Что сделано:** Подготовлены чек-листы с учетом мобильной специфики (жесты, системные настройки, обновление приложения, аппаратные прерывания — звонки, SMS, переключение сетей). Тестирование проводилось на эмуляторе **Android Studio** (конфигурация Honor 8 / Android 9.0). Сформирован финальный отчет о тестировании.
*   **Папка проекта:** [Перейти к файлам](./04-metro-android-mobile-testing/)

### 📐 4. Тест-дизайн и UX-аудит модуля «Каршеринг» веб-приложения «Яндекс Маршрутах»
*   **Описание:** Тестирование новой функциональности бронирования автомобилей в условиях неполной документации.
*   **Что сделано:** Проведен анализ макетов в Figma и сопоставление противоречивых требований. Составлены чек-листы на вёрстку элементов карты и формы бронирования, написаны тест-кейсы на логику модальных окон оплаты и привязки карт.
*   **Папка проекта:** [Перейти к файлам](./03-routes-carsharing-ui-ux/)

### 📊 5. Тест-анализ и функциональное тестирование веб-приложения «Яндекс Маршрутов»
*   **Описание:** Покрытие тестами формы расчета времени и стоимости поездки.
*   **Что сделано:** Проведена декомпозиция требований. Применены техники тест-дизайна (классы эквивалентности и граничные значения) для полей ввода. Спроектированы и проверены **тест-кейсы**, заведены **баг-репорты**.
*   **Папка проекта:** [Перейти к файлам](./02-routes-form-test-design/)

### 🔄 6. Регрессионное тестирование веб-приложения «Mesto»
*   **Описание:** Проведение релизного цикла тестирования интерактивной социальной сети.
*   **Что сделано:** Прогон регрессионного чек-листа, оформление баг-репортов с артефактами (скриншоты, скринкасты). Проведение повторного тестирования (**Retest**).
*   **Папка проекта:** [Перейти к файлам](./01-mesto-web-regression-retest/)
