# 📑 Портфолио проектов по ручному тестированию (Manual QA)

Добро пожаловать в репозиторий с примерами моей тестовой документации, тест-анализа и артефактов тестирования веб- и мобильных приложений.

Все проекты выполнены на основе реальных технических требований (ТЗ) и дизайн-макетов в Figma, прошли аудит и соответствуют индустриальным стандартам оформления QA-документации.

---

## 🗺 Навигация по проектам

### 🎓 1. Комплексное тестирование веб- и мобильного приложения «Яндекс Самокат»
* **Описание:** Сквозное End-to-End тестирование экосистемы сервиса на двух платформах (Web и Mobile).
* **Что сделано:** Проектирование чек-листов для экрана «Статус заказа» (144 проверки) и матриц валидации данных формы (102 проверки). Разработка тест-кейсов на логику нотификаций и отсутствие сети для Mobile. Проведение исследовательского тестирования и составление финального аналитического отчета.
*   **Папка проекта:** [Перейти к файлам](./06-diploma-samokat-e2e-testing/)

### ⚙️ 2. Тестирование API бэкенда веб-сервиса «Яндекс.Прилавок»
* **Описание:** Интеграционное тестирование новой функциональности API (модули корзины, наборов продуктов и интеграции с доставкой) при помощи Postman.
* **Что сделано:** Проектирование чек-листов на основе технической документации Apidoc. Тестирование REST-ручек (GET, POST, PUT, DELETE) с JSON-телами и XML-сервиса расчета доставки. Локализация серверных ошибок (500 Internal Server Error), оценка рисков безопасности и составление Test Summary Report.
*   **Папка проекта:** [Перейти к файлам](./05-grocery-rest-xml-api-postman/)

### 🚇 3. Функциональное и регрессионное тестирование мобильного приложения «Яндекс Метро» (Android)
* **Описание:** Тестирование сборки мобильного приложения на эмуляторе Android Studio после масштабного рефакторинга кода.
* **Что сделано:** Подготовка чек-листов с учетом мобильной специфики (жесты, системные настройки, прерывания, сохранение данных, логика обновлений). Выполнение прогона на конфигурации Honor 8 / Android 9.0 и составление отчета о релизе.
*   **Папка проекта:** [Перейти к файлам](./04-metro-android-mobile-testing/)

### 🚗 4. Комплексное тестирование UI/UX и логики модуля «Каршеринг» в Яндекс Маршрутах
* **Описание:** Тестирование новой функциональности бронирования автомобилей (тариф «Роскошный») в условиях неполной документации.
* **Что сделано:** Анализ макетов в Figma и применение кросс-панельного подхода (адаптация UI-kit такси). Составлены чек-листы на вёрстку элементов карты и формы (212 проверок), написаны тест-кейсы на логику окон оплаты и кнопки «Забронировать». Проведено кросс-браузерное тестирование в Яндекс.Браузере и Firefox.
*   **Папка проекта:** [Перейти к файлам](./03-routes-carsharing-ui-ux/)

### 📊 5. Функциональное тестирование и тест-дизайн веб-сервиса «Яндекс Маршруты»
* **Описание:** Покрытие тестами формы расчета времени и стоимости поездки на основе анализа документации.
* **Что сделано:** Проведена декомпозиция требований логики полей. Применены техники тест-дизайна (классы эквивалентности и граничные значения). Спроектировано и протестировано 66 сценариев, локализовано и задокументировано 18 баг-репортов.
*   **Папка проекта:** [Перейти к файлам](./02-routes-form-test-design/)

### 🔄 6. Регрессионное тестирование веб-приложения «Mesto»
* **Описание:** Проведение полного релизного цикла регрессионного тестирования интерактивной социальной сети.
* **Что сделано:** Прогон регрессионного набора тест-кейсов, локализация дефектов и оформление подробных баг-репортов с артефактами (скриншоты, скринкасты). Проведение повторного тестирования (**Retest**) и валидация жизненного цикла багов (Closed/Reopened).
*   **Папка проекта:** [Перейти к файлам](./01-mesto-web-regression-retest/)

## 🧰 Профессиональные навыки (Manual QA)

* **Тест-дизайн и анализ:** Классы эквивалентности (КЭ), Граничные значения (ГЗ), Декомпозиция требований, Кросс-панельный подход, Исследовательское тестирование.
* **Тестовая документация:** Чек-листы (функциональные, UI/UX, мобильные), Тест-кейсы, Матрицы валидации данных, Баг-репорты, Финальные отчеты.
* **Виды тестирования:** Функциональное, Регрессионное, Кросс-браузерное и Кросс-платформенное, UI/UX тестирование, Тестирование мобильных приложений (жесты, прерывания, конфигурации), Тестирование API (Интеграционное).
* **Инструменты и технологии:** Postman (REST API, методы GET/POST/PUT/DELETE, форматы JSON/XML), DevTools, Android Studio (Эмуляторы), Figma, Google Таблицы / Документы.
